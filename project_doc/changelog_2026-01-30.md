# 项目文档更新记录

## 2026-01-30

### 1. 视觉标记与绘图行为
- 新增了 `@`（显式绘制）、`#hex`（颜色）、`$`（辅助线）等视觉标记的详细说明。
- 明确了严格模式（Strict Mode）和回退模式（Fallback Mode）的判定与行为：
  - 只要脚本中出现任何标记，则仅绘制带标记的变量。
  - 若无任何标记，则默认绘制变量名为 `y` 的曲线，颜色为白色。

### 2. VM 状态管理
- 明确每次绘图前需重置虚拟机（VM）状态，防止变量残留导致的“鬼线”或旧数据干扰。
- 相关实现已在 `js/parser/vm.js`、`js/parser/evaluator.js`、`js/plotter.js` 中补充。

### 3. AST 遍历修正
- 修复了多行公式仅第一行生效的问题。
- 递归分析 `ExpressionStatement`，确保所有赋值语句的标记都能被正确识别。

### 4. 文档结构完善
- `project_doc/feature_visualization.md`：详细记录了视觉标记的设计与用法。
- `project_doc/technical_log.md`：记录了主要技术问题与解决方案。
- `project.md`：已同步上述所有核心设计与行为逻辑。
